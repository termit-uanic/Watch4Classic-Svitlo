# Wattlo в Google Play Console: шпаргалка

Здесь собрано всё, что нужно заполнить в Play Console, и как выпускать сборки. Тексты страницы приложения лежат в `store/listing/` (uk, ru, en), политика конфиденциальности и описание — в `docs/` (GitHub Pages: https://termit-uanic.github.io/wattlo/ и https://termit-uanic.github.io/wattlo/privacy/).

## 1. Выпуск сборок

```bash
tools/build_play_bundles.sh 1      # номер сборки: для каждой загрузки на единицу больше
```

Скрипт спрашивает алиас и пароли ключа загрузки (`~/.ssh/GooglePlay/upload-keystore.jks`), собирает два `.aab` и кладёт их в `~/wattlo-play/`. Телефонная сборка и часовая — это два пакета с одним именем `app.wattlo`; коды версий разные (101000000+N и 201000000+N), так что они не конфликтуют.

- Телефон: обычный трек (внутреннее тестирование → закрытое тестирование → продакшен).
- Часы: отдельный трек Wear OS. В закрытом тестировании включить Wear OS в «Расширенных настройках» и принять правила проверки.
- Включить Play App Signing (предложит сам Play при первой загрузке). Ключ загрузки — тот, что в `~/.ssh/GooglePlay`, ключ подписи Google хранит сам.
- Сборки из Play подписаны другим ключом, чем отладочные: установленное по USB приложение придётся удалить (`adb uninstall app.wattlo`) перед установкой из Play.

## 2. Закрытое тестирование (личный аккаунт, созданный после 13.11.2023)

- Нужно **не менее 12 тестеров**, которые **подписались (opt-in) и остаются в тесте 14 дней подряд**. Брать запас: 15–20 человек.
- Тестеры: адреса Google-аккаунтов (Gmail) в списке тестеров на закрытом треке, потом ссылка на участие. Приложение они ставят из Play и желательно изредка открывают.
- Условия Google меняются: перед стартом сверить с актуальной справкой Play Console.
- Через 14 дней — заявка на доступ к продакшену (ответ обычно за пару дней), потом проверка приложения.

## 4. Анкеты

**Безопасность данных (Data safety)**
- Собираются ли данные пользователя: **нет**. Разработчик ничего не получает; настройки и кеш графика остаются на устройствах.
- Передаются ли данные третьим лицам: нет. (Запрос к сайтам графиков несёт только IP-адрес и адрес страницы региона, как любой запрос; очередь и настройки не передаются. Если хочется отвечать осторожнее, можно указать «IP-адрес» как данные, обрабатываемые сторонними сайтами, но Google такие технические запросы обычно не считает сбором.)
- Шифрование при передаче: да (HTTPS). Удаление данных по запросу: не требуется, данных у разработчика нет.
- Политика конфиденциальности: ссылка из раздела 3.

**Рейтинг контента (IARC)**: категория «Утилита / справочник»; насилия, секса, азартных игр, покупок, общения между пользователей нет, местоположение не используется. Ожидаемый результат: для всех возрастов.

**Целевая аудитория**: 13+ (не для детей до 13). Приложение не привлекает детей.

**Реклама**: нет. **Покупки в приложении**: нет. **Учётная запись**: не нужна.

**Рекламный идентификатор (Advertising ID)**: приложение его не использует (разрешения AD_ID нет).

**Государственное приложение**: нет, приложение **не** представляет государство и не связано с государственными органами; в описании и на сайте так и сказано.

**Новостное, медицинское, финансовое приложение, COVID-19**: нет.

**Декларации по разрешениям**
- Точные будильники (`USE_EXACT_ALARM`): основная функция — напоминания в заданную пользователем минуту до отключения и включения света и обновление отсчёта на виджете. Текст для формы: *"The app reminds the user a few minutes before a scheduled power outage starts or ends, at a time the user chooses, and keeps a countdown widget accurate to the minute. Inexact alarms would make the reminder arrive too late to be useful."* Возможно, при проверке Google попросит убрать разрешение: в коде есть запасной вариант без точных будильников.
- Передний план (foreground service): не используется, разрешение убрано из манифеста.
- Остальные разрешения (интернет, состояние сети, уведомления, вибрация, запуск после перезагрузки, WAKE_LOCK) деклараций не требуют.

## 6. Источники графиков

- poe.pl.ua: официальный график Полтаваобленерго, только для Полтавской области.
- yasno.ua (`app.yasno.ua`): публичные данные сервиса для Киева и Днепра, источник по умолчанию для этих городов.
- GitHub (`raw.githubusercontent.com`): открытые JSON-файлы, которые собирают волонтёры: Baskerville42/outage-data-ua (ДТЕК: Киев, Киевская, Днепропетровская, Одесская области — по умолчанию там), yaroslav2901/OE_OUTAGE_DATA и vn-progr/gpv-voe-vinnytsia (остальные облэнерго — запасной источник). Лицензии у части репозиториев нет: авторам не писали, ссылки на репозитории есть в приложении (Настройки → Источники графиков) и в README.
- bezsvitla.com.ua: остальные регионы. Их условия разрешают использовать материалы с активной ссылкой на сайт: ссылка есть в приложении (Настройки → Источники графиков), на странице проекта и в README.
- energy-ua.info не используется: его `robots.txt` запрещает автоматическое чтение.
